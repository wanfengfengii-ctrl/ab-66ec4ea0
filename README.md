# 彩窗铅条骨架编排

为拆解后的彩窗规划铅条骨架：从候选铅条中联合选择**恰好「玻璃片数 − 1」条**，使

1. 全部玻璃片连通；
2. 任意子集不形成环（整体为生成树）；
3. 每片玻璃片的实际连接数落在其闭区间 `[下限, 上限]` 内。

在所有合格骨架中按优先级依次取：

- ① **最弱采用铅条等级最高**（最大化最小抗拉等级）；
- ② **总代价最低**；
- ③ **采用候选的录入序号序列（升序）字典序最小**。

不存在合格骨架时，页面稳定列出**按玻璃片编号排序**的失败证据（连接范围 / 连通性），首条即为首个无法满足的玻璃片证据。

## 快速开始（Docker）

```bash
# 静态 Web：健康检查通过后以 WEB_PORT（默认 8080）暴露页面
WEB_PORT=8080 docker compose up -d web
# 打开 http://localhost:8080

# 一次性 verify 服务：依次执行 代码测试 → 构建 → 骨架样例冒烟，退出码即结果
docker compose run --rm verify
echo $?   # 0 = 全部通过
```

## 本地开发（Node ≥ 18，无第三方依赖）

```bash
node tests/run-tests.js   # 单元测试
node build.js             # 构建 app/ → dist/
node verify/smoke.js      # 对 dist/ 做骨架样例冒烟
# 直接用浏览器打开 app/index.html 即可使用
```

## 页面使用

1. 录入 5–8 片玻璃片（编号唯一 + 连接数闭区间）与 8–14 条候选铅条（两端编号、抗拉等级、安装代价），或点击「载入样例」；
2. 点击「编排」；
3. 查看：采用 / 未采用铅条、各片实际连接数（含是否达标）、骨架结构画布、最弱采用等级与总代价；无解时查看按编号排序的失败证据。

## 骨架样例的最优解（冒烟基准）

6 片玻璃（片 6 上限 1，只能接一条）、10 条候选。唯一最优解：

- 采用序号 **#2 #3 #7 #8 #10**（0 基 `[1,2,6,7,9]`）；
- 最弱采用等级 **6**，总代价 **28**；
- 各片连接数：1→1, 2→2, 3→2, 4→2, 5→2, 6→1。

推导要点：片 6 上限为 1，候选 #8（等级 9）与 #9（等级 3）二选一；要使最弱等级 ≥ 6 必须选 #8，且片 1 只能经 #2（等级 7）接入；在等级 ≥ 6 的候选中满足片 4 上限 2 的生成树仅两棵，代价更低者为 28。

## 目录结构

```
app/            静态页面（index.html / styles.css / app.js）与可复用求解器（solver.js）、样例（sample.js）
tests/          求解器单元测试（Node 原生 assert，无依赖）
verify/         骨架样例冒烟脚本
build.js        构建脚本：app/ → dist/ 并自检
Dockerfile      verify（一次性校验）/ build / web（nginx）三阶段
docker-compose.yml  web（WEB_PORT 可配置 + 健康检查）与 verify（一次性，退出码报告）
```
